About This Project

On January 21, 2026, I ran an experiment. I gave three of the world's most sophisticated AI coding agents the same mathematical problem and let them work autonomously. The problem was Project Euler 763, "Amoebas in a 3D Grid," a combinatorics challenge that has been solved by only 202 humans in the five years since its publication.

Only one system found the correct answer.

This site contains the full story: what each system tried, where they succeeded and failed, and what it tells us about the current state of AI reasoning. The essay is a substantial read, approximately one hour, but if you're interested in how AI systems actually think through hard problems, it's worth your time.

The Problem

Project Euler 763 asks: how many distinct arrangements of amoebas are possible after 10,000 divisions in a 3D grid, where each amoeba divides into three offspring at adjacent positions?

The answer requires understanding deep combinatorial structure. Brute-force enumeration is impossible. The solution demands mathematical insight.
